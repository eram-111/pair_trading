PART 2 — EXCEL: THE PULL (~90 min, time-boxed)
------------------------------------------------
Open Excel ON THE TERMINAL PC (via Bloomberg/Start menu, so the
Bloomberg ribbon tab is present).

TARGET LAYOUT (one sheet per FIELD — 19 sheets, NOT per company):

     A              B                C                ...   AO
1    PE_RATIO                                               <- A1 = field code (only cell you change per sheet)
2                   AAPL US Equity   MSFT US Equity   ...   <- row 2 = 40 tickers
3
4    3/31/2015      24.13            19.85            ...   <- grid fills itself
...  ...            ...              ...
44   12/31/2024     ...              ...

STEPS:
 1. A1: type first field code:  PE_RATIO
 2. B2: paste the full ticker list (bottom of this sheet), then with
    B2 selected:  Data tab -> Text to Columns -> Delimited -> Next ->
    tick Comma -> Finish.   (tickers spread across B2:AO2)
 3. A4: type (shows dates + first ticker's values):

    =BDH(B$2,$A$1,"12/31/2014","12/31/2024","Per=CQ","Days=A","Fill=P")

 4. C4: type (values only — note the extra "Dts=H"):

    =BDH(C$2,$A$1,"12/31/2014","12/31/2024","Per=CQ","Days=A","Fill=P","Dts=H")

 5. Copy C4 across: click C4 -> Ctrl+C -> select D4:AO4 -> Ctrl+V
 6. WAIT for the status bar to finish (BDH fills asynchronously).
    Stalled? Bloomberg ribbon -> Refresh All.
 7. Save this sheet: F12 -> File name = field code (PE_RATIO) ->
    Save as type: CSV (Comma delimited) -> Save -> "active sheet
    only" warning -> Yes.
 8. Next field: right-click sheet tab -> Move or Copy -> tick
    "Create a copy" -> OK -> on the copy change ONLY A1 to the next
    field code -> wait -> F12 -> save CSV under that field's name.
 9. Repeat until the checklist below is done.
