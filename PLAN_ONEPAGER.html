The 4-Day Build

Three people, three parallel lanes. Each of us owns one way of picking stock pairs, one prediction model, and the testing of that model. The measuring tools — backtester, training-data builder, scoring code — are built once and shared, so every method is judged by the same referee. We hand each other data files with agreed formats, never half-finished code, so nobody waits on anybody.

The safety rails

Nobody waits

Fake-data stand-ins with known answers let all three lanes start at full speed on Day 1 — real data slots in when it lands.

Nobody peeks at the future

Rolling windows only, labels purged near split boundaries, and the pipeline must find nothing in pure random noise. If a result looks amazing, we treat it as a bug first.

Nobody collides

Every file has exactly one owner; hand-offs are data files with frozen formats. Two short syncs a day keep the lanes aligned.

If we fall behind

A pre-agreed cut list: Track C drops to validation-only first, then figures. The core comparison — Track A, E1 vs the fixed rule — always survives.

Full detail — tasks, hours, contracts, risk register — lives in IMPLEMENTATION_PLAN.md in the repo. The grid: 3 pairing methods × 4 models = 12 cells, one referee.
